# Petrol Pump Admin Portal

A web-based Petrol Pump Management System developed for managing daily petrol pump operations.

## Features

- Dashboard
- Tank Management
- Nozzle Management
- Fuel Stock Management
- Employee Management
- Sales History
- Reports

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL

## Installation

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file with the required environment variables.
4. Start the server.
